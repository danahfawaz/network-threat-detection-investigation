# Validation

Validation is split into two clearly separate parts:

1. **Synthetic validation**: automated, using captures built for this project.
2. **Real public PCAP validation**: manual, using a legitimate public capture.

---

## Synthetic validation

### Sample captures

The captures in [`samples/`](../samples) are generated by
[`scripts/generate_samples.py`](../scripts/generate_samples.py) with a fixed random seed. They
contain only fictional traffic (private and documentation IP ranges, reserved domain names,
locally administered MAC addresses, filler payloads).

| Sample | Packets | Expected findings | Overall risk |
|---|---|---|---|
| `benign_traffic.pcap` | 2,088 | none | 0 (none) |
| `port_scan.pcap` | 1,193 | Port Scan | 80 Critical |
| `dns_anomaly.pcap` | 1,864 | Suspicious names, failed lookups, query flood | 65 High |
| `repeated_connections.pcap` | 1,569 | SSH password guessing, watchlist port 4444 | 85 Critical |
| `traffic_burst.pcap` | 4,272 | Traffic Burst | 65 High |
| `beaconing.pcap` | 4,380 | Beacon-Like Connections | 80 Critical |
| `arp_spoofing.pcap` | 1,258 | ARP Spoofing | 80 Critical |
| `mixed_investigation.pcap` | 4,968 | all 7 findings | 100 Critical |

The ground truth is stored in [`samples/expected_detections.json`](../samples/expected_detections.json)
and `tests/test_pipeline_samples.py` checks that each file gives **exactly** those findings.

### Automated test suite (136 tests)

| Area | File |
|---|---|
| File loading, validation, empty / corrupted / truncated / wrong-type files, limits | `test_loader.py` |
| Packet normalization, traffic statistics | `test_normalize_and_traffic.py` |
| Each detection rule, threshold boundaries, normal traffic not flagged | `test_port_scan.py`, `test_dns_anomaly.py`, `test_connection_attempts.py`, `test_traffic_burst.py`, `test_beaconing.py`, `test_arp_spoofing.py` |
| Risk scoring and severity | `test_scoring.py` |
| End-to-end on every sample, no-IP and single-packet captures, config changes | `test_pipeline_samples.py` |
| HTML report (incl. HTML-escaping of packet data), CSV (incl. formula injection), JSON, evidence helpers | `test_reporting.py` |
| Command-line interface | `test_cli.py` |
| Dashboard via Streamlit AppTest: start page, analysis, every sidebar view, friendly errors, settings | `test_dashboard.py` |
| Analysis in a fresh Python process (guards against Scapy layers not being loaded) | `test_fresh_process.py` |

Run everything with:

```bash
python -m pytest
```

The same suite runs on GitHub Actions for every push (`.github/workflows/tests.yml`).

## Final local validation checklist (about 15 minutes)

1. **Install**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate          # Windows  (macOS/Linux: source .venv/bin/activate)
   pip install -r requirements.txt
   ```
2. **Optional: run the tests**: `python -m pytest` → all tests pass.
3. **Start the dashboard**: `streamlit run app/streamlit_app.py` → the browser opens.
4. **Upload a sample**: drag `samples/mixed_investigation.pcap` into the upload box (or use
   *Use a sample capture*), then click **Analyze PCAP**.
5. **Dashboard loads**: 4,968 packets · 16 IP addresses · 7 threats · risk 100/100 · 6 min 58 sec.
6. **Expected detections appear**: Beacon-Like Connections, Port Scan, DNS Anomaly, 2× Repeated
   Connection Attempts, Traffic Burst, ARP Spoofing.
7. **Open one or two details** with **View** (for example Port Scan and ARP Spoofing).
8. **Evidence and risk explanation appear** in the detail view ("Why this risk score").
9. **Export the investigation report**: Investigation Actions → *Export Investigation Report* → open the HTML file.
10. **Export alerts as CSV**: *Export Alerts (CSV)* → open it in Excel.
11. **Optional: test one real public capture** and fill in the table above.
12. **Take 3–4 screenshots** and save them in `docs/screenshots/` with these exact names
    (the README already links to them):
    - `dashboard.png`: main dashboard after analyzing `mixed_investigation.pcap`
    - `investigation-detail.png`: the detail view of one finding
    - `threat-timeline.png`: the Threat Timeline view
    - `investigation-report.png`: the top of the exported HTML report
